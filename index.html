Photoshop Production Showcases

Action Sports Composite

To create this dynamic action composite, I isolated the running football players using the Quick Selection Tool and refined the edges with the Select and Mask workspace to cleanly separate hair and helmet details from the raw background. I then generated a localized high-contrast atmosphere using custom Adjustment Layers (Curves and Hue/Sat) paired with precision brushwork on the layer masks to emphasize highlights along the players' silhouettes.
